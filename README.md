# 格间

安装：`npm ci`

本地启动：`npm run dev`，访问终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:18260 。

## 听读模式与键盘操作

棋盘是单一焦点（`role="grid"` + `aria-activedescendant`），Tab 一次进入棋盘后：

- 方向键按行列移动（Home/End 到行首/行尾，PageUp/PageDown 到列首/列尾）
- `F` 填涂 · `X` 标空 · `E`/`Backspace` 擦除 · 空格/回车应用当前工具
- `R` 朗读行线索 · `C` 朗读列线索 · `U` 撤销

提示与检查的结果进入右侧「听读队列」：选中条目可免费再次朗读，未过期的条目能回到对应格子；过期条目只保留回听。保存失败、扣费确认与完成结果按优先级保留，刷新后未处理的重要消息仍会恢复。所有操作（鼠标或键盘）都经过同一提交协议，提示额度不会因重复朗读或重复提交而重复扣除。
